Primary insight. The suite is broad and disciplined: every module is covered, regression/symmetry/edge cases are heavily tested (50 / 51 / 106 tests). The weaknesses are structural, not absent: (1) 7 public symbols are never called anywhere; (2) the project's own "every level plays a full legal game and loses to the level above" standard was missing a named self-play gate for only L1 and L3 (now added — see G2); (3) special-move evaluation and the L6 headline result are not locked by end-to-end tests. Confidence: High for module coverage and dead-symbol findings (repo-wide grep); Medium for the ladder-gating and special-move gaps (inferred from intent classification + keyword probes — confirm by reading test bodies).

4. Strengths

  • Complete module coverage: all 15 src modules + bench/rating + the L3.5 and L6 experiments have dedicated test files (692 test functions total).
  • Strong regression discipline (50 regression-intent tests), including the 5 L6 bugs and the safety-proxy fix — these cannot silently return.
  • Canonicalisation / symmetry is the best-covered property (51 canonical-intent tests), matching the project's emphasis on colour-mirror correctness.
  • Edge-case heavy (106 tests) and reproducibility asserted (37 tests) per the standard.
  • Search internals covered: MVV-LVA ordering, transposition table, quiescence, iterative deepening all have functional tests.
  • Round-trip / persistence covered (41 tests): ledgers, weights, configs, and model checkpoints serialise and reload correctly.

G1HighDead / uncalled public surface (7 symbols)
Repo-wide grep shows these 7 public symbols are defined but never called anywhere in src/, bench/, or tests/. Either dead code to prune or public API with zero tests — untested either way.
Evidence: square_to_rc, rc_to_square, squares_to_mask, flip_colour (bitboard); encode_canonical_for_move_space (encode); attacked_by_mask (masks); move_feature_vector (perceptron). Each has exactly 1 repo occurrence (its own def).		RESOLVED 2026-10-03. 6 utilities tested as public API (test_bitboard.py, test_encode.py, test_masks.py: square_to_rc, rc_to_square, squares_to_mask, flip_colour, encode_canonical_for_move_space, attacked_by_mask). The 7th, move_feature_vector, was a dead duplicate of the real _move_features path and was pruned from perceptron.py.
G2HighLadder gating is uneven across L1–L6
The project's stated standard is 'every level plays a full legal game to a real result, is seed-reproducible, and loses to the level above'. This is met strongly for L2 (search) but unevenly for the others.
Evidence (corrected on reading test bodies — the intent-classification count understated this): the named 'plays a full legal game to a real result' gate already existed for L5 (test_guided.py:285), L6 (test_ensemble.py), L2-wrapper (test_search.py:527), L3.5 (test_squarelocal.py:137), and L4 (test_torch_model.py:248, 'usable as a move policy in a game'). The genuine gap was narrower: only L1 and L3 lacked a dedicated self-play gate (both were exercised only as opponents or in draws).		RESOLVED 2026-10-03. Added test_factored_softmax_plays_a_full_legal_game_to_a_real_result (L1, test_policy.py) and test_policy_plays_a_full_legal_game_to_a_real_result (L3, test_perceptron.py), mirroring L5's gate (valid termination reason, every recorded move replayed and confirmed legal, ply-cap reported as unfinished not a draw). Every level now has an explicit self-play full-game gate.
G3MediumSpecial-move *evaluation* is untested
Masks correctly admit castling / en passant / all 4 promotions (legality gap-free), but value.evaluate() is material+PST only — no castling term, no en-passant term, no mobility term, and encode() has no castling-rights channel. The known census ('search castles, blind does not') is documented in memory but is NOT locked by any regression test.
Evidence: castling 10 / en passant 12 / promotion 22 occurrence counts in tests (legality only). No test asserts eval rewards or reflects castling/ep, and no test locks the measured underplay census.		RESOLVED 2026-10-03. test_masks.py: castling (both sides/colours), en passant, and all 4 promotions are legal and admitted by the mask (no legality gap). test_diagnostics.py: test_the_castling_census_search_castles_blind_does_not pins the census — depth-2 search castles every game, blind L1 and untrained L3 never do (marked as a characteristic, not a correctness invariant).
G4MediumL6 headline result pinned only at the weight level, not the play level
The corrected L6 result ('absolute weights make the ensemble lose to L2-d2; relative weights make it tie') is asserted via weight values (blind>search, relative collapses to best) but not via an end-to-end game-result regression.
Evidence: test_the_fitted_ensemble_is_worse_than_its_best_member asserts weight magnitudes; test_relative_weighting_collapses_to_the_best_member asserts weights. No test plays the ensemble vs L2-d2 and locks the win/loss/draw outcome under each rule.		RESOLVED 2026-10-03. test_bench.py: test_absolute_weights_make_the_ensemble_lose_to_its_best_member (loses every game, mated fast) and test_relative_weights_make_the_ensemble_survive_like_its_best_member. Note: the relative assertion was refined during implementation — the relative ensemble is ~97% L2-d2 + 3.2% noise so it still loses, the robust signal being that it survives ~2.25x longer than the absolute ensemble rather than blundering early.
G5MediumNo adversarial legality guard on the game loop
Every game-play test uses a policy that is *supposed* to be legal. Nothing feeds a malicious/random move generator through play_game and asserts the loop rejects or validates illegal moves — despite the rule that python-chess is the sole authority on legality.
Evidence: No test references illegal-move injection or validation of select() output against board.legal_moves at the loop boundary.		RESOLVED 2026-10-03. test_game.py: test_play_game_rejects_an_illegal_first_move and test_play_game_rejects_an_illegal_move_after_legal_ones. play_game already validated select() against board.legal_moves; these tests now exercise that guard (immediate and mid-game) so a refactor that drops it fails loudly.

RESOLVED 2026-10-03. test_search.py: test_transposition_table_reduces_the_node_count. Opening at depth 4: with-TT 2049 nodes / no-TT 3254 (37% saving, 96 hits).
