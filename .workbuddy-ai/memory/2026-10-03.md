## Test-suite audit (planning-graph-coding workflow)

Read-only inventory + gap analysis of the whole suite. Deliverable:
`tests/TEST_SUITE_AUDIT.html`; re-runnable tooling in `tests/_audit/`
(`_inventory.py` AST inventory, `_analyze.py` coverage map + intent classification,
`_report.py` HTML render). Method: AST parse of 17 test files + 15 src modules,
whole-word symbol reference counting repo-wide.

**Numbers:** 692 test functions across 17 test files; every src module has a test
file (module coverage complete). Intent distribution: unit_behaviour 412,
edge_case 106, regression 50, canonical 51, reproducible 37, roundtrip 41,
legal_game 28, ladder 9, special_moves 11, performance 7.

**Key findings (gaps):**
- G1 (High): 7 public symbols are defined but never called *anywhere* in src/,
  bench/ or tests/ — dead code or untested public API: `square_to_rc`, `rc_to_square`,
  `squares_to_mask`, `flip_colour` (bitboard); `encode_canonical_for_move_space`
  (encode); `attacked_by_mask` (masks); `move_feature_vector` (perceptron).
- G2 (High): the stated testing standard ("every level plays a full legal game to a
  real result, is seed-reproducible, loses to the level above") is enforced strongly
  for L2 only. L1 has no dedicated full-game test (used only as opponent); L3 gated
  on "draws L1" not "loses to L2"; L4/L5 gated via parity (L4≈L3, L5≈L4), not the
  game-result gate. Explicit "loses to above" assertions exist for ~7 relationships,
  all around L2.
- G3 (Med): special-move *evaluation* untested. Masks admit castling/ep/promotion
  (legality fine) but `value.evaluate()` is material+PST only (no castling/ep/mobility
  term, no castling-rights plane in encode). The known census "search castles, blind
  does not" is documented in memory but not locked by a regression test.
- G4 (Med): L6 headline result pinned only at weight level
  (`test_the_fitted_ensemble_is_worse_than_its_best_member`,
  `test_relative_weighting_collapses_to_the_best_member`), not via end-to-end game
  result. No test plays absolute vs relative ensemble vs L2-d2 and locks the outcome.
- G5 (Med): no adversarial legality guard — no test feeds an illegal `select()`
  through `play_game` and asserts rejection/raise.
- G6/G7 (Low): search TT node-saving (~37% documented) not locked; encode() plane
  helpers have no direct per-plane assertions (only indirect via full encode).

**Strengths worth keeping:** complete module coverage; strong regression discipline
(50 tests, incl. the 5 L6 bugs); canonicalisation/symmetry best-covered property
(51 tests); edge-heavy (106); search internals (MVV-LVA, TT, quiescence, iterative
deepening) functionally tested; round-trip/persistence covered (41).

**Confidence:** High for module coverage + dead-symbol findings (repo-wide grep);
Medium for ladder-gating + special-move gaps (inferred from intent classification +
keyword probes — confirm by reading test bodies).
