  `--eval-games`, `--seed`, `--out-dir`. Bootstraps repo root + src onto
  sys.path (so it runs on Kaggle too). Writes model json + meta + results.json
  + summary.md. Reloads the trained model from disk for the eval (tests the
  save/load path).
