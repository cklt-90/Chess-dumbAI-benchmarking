## H15 verified: the baseline is non-comparable, but the cause was not the book

Ran H15 — the review's top recommended next item — because every
baseline-derived rating quotes `bench/results-2026-10-02.json`.

### Setup

- Commit `17fcbe1` landed the doc pass (review, tier-2 paper, ledger). Tree clean.
- H15's stated claim: the `book[i // 2]` → `book[i]` fix (plus a book with
  Black-to-move entries) makes pre-fix results non-comparable.

### What was run

1. **Reproduced the harness is deterministic.** `material vs L2-d1` gave
   `0-1-5` on three consecutive runs, but the stored row is `0-2-4` — a real
   difference, not noise.
2. **Book-indexing test.** Replayed the pair under `book[i % n]` (fixed) → `0-1-5`
   and `book[i // 2]` (pre-fix) → `0-0-6`. **Neither** reproduces the stored
   `0-2-4`, so the book is not the cause.
3. **Full-roster census.** 6 games/pair, all 21 stored pairs: **12 agree, 9
   differ.** Every differing row involves a level that consumes
   `value.evaluate()` (`material`, `L2-*`) or `L3`.
4. **Attribution by active revert.** Zeroed `king_shelter_score` in-process and
   replayed the 9 drifting pairs: **7 restore exactly**
   (`material vs L2-d1` 0-2-4, `material vs L2-d2` 0-0-6, `material vs L3`
   3-0-3, `L2-d1 vs L2-d2` 0-5-1, `L2-d1 vs L2-d3` 0-3-3, `L2-d2 vs L2-d3`
   0-4-1, `random vs material` 0-0-5-1). **2 do not**: `random vs L3` and
   `L2-d1 vs L3` — **both involve `L3`.**

### Finding

**H15 is SUPPORTED IN OUTCOME, CORRECTED IN MECHANISM.**

- The baseline genuinely does not reproduce — H15's conclusion holds.
- The cause is **`king_shelter_score`**, added to `evaluate()` after the
  baseline by the H23 fix (the only addition to `evaluate()` since `efcc242`),
  **not** the opening book.
- The book is ruled out twice: `bench/runner.py` was committed **already fixed**
  in the **same commit** as the baseline (`efcc242`), and the pre-fix indexing
  does not reproduce either. The memory log for 2026-10-02 records the book
  fixes landing *before* the 424s baseline run whose `seconds` matches the
  stored `423.927`.
- The residual 2 rows are the **perceptron change**: L3's input width default
  moved `TOTAL_CHANNELS`(28) → `BINARY_CHANNELS`(24), alongside the `grad_ctx`
  chain-rule fix.

**Consequence:** the re-baseline boundary is the **evaluator** change. Every
pre-`king_shelter` rating is incomparable to every post-`king_shelter` one.
